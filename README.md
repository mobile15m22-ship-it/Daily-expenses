# হিসাবখাতা - Daily Expense Tracker

১০০% ফ্রি ও নিরাপদ দৈনন্দিন খরচের হিসাব খাতা।

## 🚀 বৈশিষ্ট্যসমূহ
- **Firebase Firestore ক্লাউড ডাটাবেজ:** প্রজেক্ট `firewritter-500cd` এর সাথে সরাসরি সংযুক্ত।
- **মোবাইল ফ্রেন্ডলি:** যেকোনো স্মার্টফোন দিয়ে সহজে ব্যবহারযোগ্য।
- **অফলাইন ব্যাকআপ:** CSV ও JSON ফরম্যাটে এক ক্লিকে ব্যাকআপ নেওয়ার সুবিধা।
- **বাজেট ও অ্যানালিটিক্স:** মাসিক বাজেট লিমিট এবং বিস্তারিত চার্ট।

## 📦 লোকালভাবে রান করার নিয়ম
```bash
npm install
npm run dev
```
